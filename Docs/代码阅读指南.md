# 《千秋策》代码阅读指南

> 起点：`Assets/_Project/Scripts`，共 50 个 C# 文件、约 13,500 行。
> 建议总节奏：第 0–2 步是理解全项目的关键（约 4,000 行），第 3 步逻辑最密单独留时间，UI 层可"用到再看"。
> 每个文件头部的块注释都写了"为什么这样做"，读文件时先读头注释再读代码。

## 一张牌打出去的全流程（读完后对照验证）

```
玩家拖牌 (UI/Cards/CardDragPlay)
  → CardPlayDirector：校验目标/费用 (PlayerState.CanAfford)
    → 扣费 (PlayerState.TrySpend)
    → 单位卡：UnitDeployer → BattlefieldManager → BattleRow
    → 策略卡：CardEffectResolver → BattleRules 判定 → FieldUnit/BuildingManager
  → 事件广播 (EventManger: CardPlayed)
  → UI 刷新 (HandUI / CommandPointController)
  → 回合推进 (TurnController)
```
